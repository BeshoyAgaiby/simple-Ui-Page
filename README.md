# Bakery Website

## 📌 Overview

A responsive bakery website built using HTML, CSS, and Bootstrap. The project showcases a modern bakery landing page with a clean layout, attractive sections, and a user-friendly design.

## 🚀 Features

* Responsive design for all devices
* Modern and clean user interface
* Bootstrap grid system and components

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5

## 🎯 Learning Outcomes

* Building responsive websites with Bootstrap
* Using Bootstrap components and grid system
* Creating structured and user-friendly layouts
* Improving frontend development fundamentals
